# C++ 文件编码

- `Iocp20Coroutine` 中大部分项目自有的 C++ 源文件（`.h`、`.cpp`）使用 UTF-16 LE 编码。
- 修改这些文件时，先确认原文件编码，并保持原编码不变；不要转换为 UTF-8、GBK 或 ANSI。
- 第三方库及其源文件不适用上述约定，应遵循对应库本身的文件编码和维护规则。

## 字符串编码

- 程序运行时的字符串默认使用 UTF-8。
- 源码中的中文字符串字面量按 GBK 编码；传给使用 UTF-8 的接口前，必须显式使用 `StrConv::GbkToUtf8(...)` 转换。
- 仅在接口明确要求 GBK（例如部分日志输出）时，才将 UTF-8 字符串转换为 GBK；不要让 GBK 字符串在内存中继续传播。
