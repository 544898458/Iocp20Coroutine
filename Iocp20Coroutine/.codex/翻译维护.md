# 翻译维护

- 翻译数据的源文件是 `表/单位.xlsx` 的“翻译”工作表，列为 `Key`、`中文`、`英文`。新增或修改翻译时维护此工作表，不直接编辑导出的 YAML。
- C++ 文案使用 `读Yaml配置::翻译Gbk("Key中文原文")` 查找翻译。Key 必须与 Excel `Key` 列逐字一致；中文原文和英文译文分别填写在 `中文`、`英文` 列。
- 只在一个位置使用的 Key 直接写在翻译调用中，不必在 `翻译Key.h` 增加常量。相同 Key 在多个位置复用时，再考虑定义到 `翻译Key.h`，并统一通过该常量引用。
- 带参数的文案使用 `读Yaml配置::翻译formatGbk("Key含{}占位符", 参数...)`；Excel 中的 Key、中文和英文文案应保留相同数量及顺序的 `{}` 占位符。
- 修改 Excel 后，按项目既有流程从源表重新导出配置；不要把生成目录中的 YAML 当作翻译源文件。
